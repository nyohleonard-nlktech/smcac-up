Comment fonctionne la formation SMCAC Academy ?

De l'inscription jusqu'à votre certificat, voici exactement ce qui se passe à chaque étape — que vous vous inscriviez seul(e) ou à travers votre entreprise.

1

Inscription

Deux façons de commencer : vous inscrire vous-même, ou être ajouté(e) par votre entreprise.

  • personIndividuel : créez votre compte, choisissez votre parcours de formation.
  • apartmentEntreprise : votre entreprise s'inscrit d'abord, puis vous recevez un code personnel par WhatsApp pour rejoindre votre espace.
2

Module 1 — accès gratuit et immédiat

Dès votre inscription, vous accédez gratuitement au premier module théorique de votre parcours. Vous le suivez à votre rythme, puis validez un court quiz (70% minimum requis) pour obtenir votre attestation du Module 1.

3

Paiement & déblocage du Module 2

Le règlement se fait directement avec l'équipe SMCAC sur WhatsApp — un bouton dans votre espace pré-remplit le message pour vous.

  • personIndividuel : un tarif unique pour débloquer le Module 2.
  • groupsEntreprise : un tarif dégressif selon le nombre de collaborateurs inscrits. L'entreprise choisit ensuite elle-même quels collaborateurs reçoivent l'accès parmi les places payées.
4

Module 2 — 90 jours d'accès

Une fois débloqué, vous disposez de 90 jours pour suivre le second module et valider son quiz de fin de parcours. Comme pour le Module 1, la réussite délivre automatiquement votre attestation, vérifiable en ligne.

5
auto_awesomeMaster Class

Formation finale spéciale — Modules 3 & 4

Les deux premiers modules validés, vous accédez à une formation finale spéciale composée de deux modules supplémentaires — le Module 3 et le Module 4 — de véritables master classes conçues pour approfondir et mettre en pratique tout ce que vous avez appris, en interaction directe avec l'équipe SMCAC. Cette formation finale se déroule selon la formule de votre choix :

location_onPrésentiel chez SMCAC
businessIntra-entreprise
videocamEn ligne
verified

Certification

Les Modules 3 et 4 complétés, vous recevez votre certificat SMCAC Academy. Chaque attestation porte un code unique, vérifiable à tout moment par n'importe qui via notre page de vérification publique.

Prêt(e) à commencer ?

Le Module 1 est gratuit — inscrivez-vous et accédez-y dès maintenant.
