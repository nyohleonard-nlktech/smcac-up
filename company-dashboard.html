Remplissez le formulaire "Demander le paiement" en précisant le nombre de places. Un message WhatsApp pré-rempli s'ouvre avec l'administrateur pour finaliser le règlement. Une fois validé, attribuez ces places pour débloquer le Module 2.

3. Choix d'Évaluation Finale

Une fois la théorie terminée, cochez le mode d'évaluation finale souhaité pour vos collaborateurs dans la section dédiée et transmettez votre demande sur WhatsApp :

  • videocam En ligne (Meet / Zoom)
